# 🔢 Infix to Prefix Conversion & Evaluation in C

## 📌 Overview
This repository contains my **C implementation** for converting **infix expressions to prefix notation** and evaluating them using **stack-based operations**. The program provides functionalities for:
- ✅ **Reading equations from a file**
- ✅ **Checking the validity of expressions**
- ✅ **Converting infix expressions to prefix notation**
- ✅ **Evaluating prefix expressions**
- ✅ **Writing results to an output file**

## 🛠 Features
- ✅ **Stack-based implementation** for efficient parsing.
- ✅ **Handles parenthesis and operator precedence correctly.**
- ✅ **Supports operators:** `+`, `-`, `*`, `/`, `^`.
- ✅ **Handles multi-digit numbers correctly.**
- ✅ **Memory management with dynamic allocation.**

## 📂 Contents
- 📜 **C Source Code:** Implementation of the algorithm.

## 📌 Requirements
- C Compiler (GCC, Clang, or MSVC)
- Basic knowledge of stacks and expression evaluation
